# V1 Scope

## Owner

- Log in.
- Manage stylists.
- Manage services.
- Set salon operating hours.
- Set stylist availability.
- View all bookings.
- View basic dashboard metrics.

## Stylist

- Log in.
- View personal schedule.
- Add walk-in bookings.
- View booking history.

## Customer

- Browse services and stylists.
- View available slots.
- Book without login.
- See confirmation after booking.

## System

- Prevent double booking.
- Store appointment timestamps in UTC.
- Display booking times in the salon timezone.
- Work on mobile and desktop.

## Later

- Customer accounts.
- Online payments.
- SMS/email reminders.
- Holidays and one-off time off.
- Multi-location support.
- AI features.
